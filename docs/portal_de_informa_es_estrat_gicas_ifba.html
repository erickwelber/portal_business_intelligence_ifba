Guia de Implementação no Microsoft Power BI

Fórmulas DAX, visual HTML Content e Mapeamento de Colunas

1. Mapeamento das Colunas Físicas da Base

Certifique-se de que sua tabela importada no Power BI (ex: TabelaPaineis) tenha as seguintes colunas e tipos de dados categorizados:

Nome Físico na Base Papel no Dashboard Categoria de Dados (Aba Modelagem)
Nome do Painel / Titulo Título principal em destaque no Card Não categorizado
Descricao Texto explicativo da utilidade do painel Não categorizado
Link URL de destino no botão "Acessar Painel" URL da Web (Web URL)
Imagem Foto/capa superior do painel URL da Imagem (Image URL)
Setor Filtro / Segmentador de dados 1 (ex: PROEN, DGP, PRODIN) Não categorizado
Tipo Filtro / Segmentador de dados 2 (ex: Gestão de Pessoas, Ensino) Não categorizado

Alternativa 100% Nativa: Visual "Cartão (novo)" / New Card

  1. Insira o visual Cartão (novo) no relatório e adicione o campo Titulo.
  2. Na formatação do visual, vá em Cartões > Imagem, marque URL da Imagem e selecione a coluna Imagem com posição Superior (Top).
  3. Em Rótulos de Referência (Reference Labels), adicione a coluna Descricao posicionada abaixo do valor principal.
  4. Ative a opção Sombra e defina o Raio do canto como 14px.
  5. Adicione um botão nativo do Power BI com o texto "Acessar Painel" e configure a Ação como URL da Web dinâmica baseada no campo Link.
